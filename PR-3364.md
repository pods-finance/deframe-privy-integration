# Test the six BRL → USD preview quotes

Open [the local Privy quote page](http://localhost:5364/pr-3364). If the local server has stopped, run `./start-preview.command` from this checkout, then open the page again. The launcher reads the existing Privy app ID and loads the isolated preview customer's key using the local `deframe` AWS profile. An existing `DEFRAME_PREVIEW_API_KEY` can also supply the key. The API key stays in the local server process.

Select **Get quote** on any row. Each row requests one unit of its input. Expand **Request** to see the exact URL. In the response, check HTTP 200, a fresh `quote.id`, the destination chain and contract in `quote.tokenOut`, and a positive `amount`. Both USD outputs have six decimals. For example, a raw amount of 170000 represents 0.17 tokens. Check the quoted deadline and any liquidity status before interpreting a response. If a request times out or the five-minute FX lock expires, request a fresh quote.

| R$1 by Pix | 100 | USDC | USDT0 |
| 1 BRLA on Polygon (137) | 1000000000000000000 | USDC | USDT0 |
| 1 BRS on Base (8453) | 1000000 | USDC | USDT0 |

The Pix requests use the BRL-KYC-approved Safe `0xBDFfcEF09a027BfA147E11D2e240853914Fc210a`. Use **Connect Privy wallet** and **Use connected Privy smart wallet** to test a different destination with its own BRL KYC. Crypto requests use walletless discovery. All six use `preferredProvider=pods` and default pricing. Pix may create an unpaid ticket; the page only requests quotes and never calls a signer or fulfillment endpoint.

For direct API testing, open [the six HTTP requests](./pr-3364.http) in VS Code REST Client with `DEFRAME_PREVIEW_API_KEY` available to the extension. Their base URL is `https://pr-3364.preview.pods.finance`. This preview follows PR #3364 and requires the PR to stay open with a preview label.

Sign in to the [Privy app](http://localhost:5364/pr-3364/pix) and open **Pix onramp** or **Pix offramp**. Pix onramp defaults to your connected Privy EVM smart wallet. Choose **Test Safe (0xBDFf…210a)** under **Destination wallet** to receive there instead. Switching recipients clears the displayed QR. The receiving address needs BRL KYC approval. Pix offramp uses your connected Privy wallet as its funding address. For an onramp, select the destination chain and token, enter the BRL amount and choose **Generate Pix QR**. Scan the code with your bank app. For an offramp estimate, select the origin chain and token, enter the amount and choose **Get payout quote**.
